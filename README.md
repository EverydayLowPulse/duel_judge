# デュエマルール判定 AI

## 概要

デュエマのルール判定を代行するAIです。
チャットUIに状況の詳細を入力すると、質問に関連するカードを選択するダイアログが表示されます。
カードの選択が完了すると、回答フェーズに入り、AIがテキストの確認、関連ルールの参照を経て推論し、回答します。

## 開発理由

デュエマは今年で25周年を迎えるご長寿コンテンツです。

それだけに、初期と比べると非常にカード能力が多様化し、複雑な挙動をするカードも増えました。インフレにより一度の盤面に絡んでくるカード枚数が増えたことも相まって、現代デュエマにおけるルール判断は非常に難解で、カジュアルプレイヤーにおける大きな障壁となっています。

いちプレイヤーとしてこの問題を解決するため、誰でも自然言語でカジュアルに問い合わせられるルール判定AIを開発しようと思い立ちました。

## 想定ユーザー層
**メインターゲット**
ルールについての知識に乏しいカジュアルプレイヤー
**サブターゲット**
その他ガチ勢（ガチ勢にとっても普通にデュエマのルールは難解）

#### ポートフォリオとしての補足事項
カジュアル層はあまりこのようなサービスにお金を払いたがらない上、そもそもデュエマはカジュアルプレイヤーの少ない煮詰まり切った環境なので、個人がビジネスにするには厳しいだろう、と考えています。あくまで趣味としての開発とご理解ください。

## 想定ユースケース
**カジュアル勢**
- 対戦時のジャッジとして当AIを用いる

**ガチ勢**
- 意見が割れたときに当AIを用いてルールの根拠を検索し、相手に見せる
- デッキを構築するにあたり関連するルール判断を当AIを用いて確認する
