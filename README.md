# デュエマルール判定 AI

## デモ

https://web-two-tau-e2mnzze5db.vercel.app/

## 概要

デュエマのルール判定を代行するAIです。

チャットUIに状況の詳細を入力すると、質問に関連するカードを選択するダイアログが表示されます。
カードの選択が完了すると、回答フェーズに入り、AIがテキストの確認、関連ルールの参照を経て推論し、判断根拠とその出典も含めて回答します。

ChatGPTなどの汎用AIと異なる点として、システム側で予め、デュエマのルール判定向けに最適化した思考フローを定義しています。例えば、質問から能力の誘発条件や処理順といった論点を先に洗い出し、関係するルールを絞り込んでから答えさせています。

また、回答に含まれる引用が取得した公式の文面に実際にあるかを機械的に照合し、見つからない場合には弾くことで、ハルシネーションのリスクを低減しています。併せて、出典を必ず示すことで、ユーザー自身が信憑性を確認できるようにし、信頼性を担保しています。

## 開発理由

デュエマは今年で25周年を迎えるご長寿コンテンツです。

それだけに、初期と比べると非常にカード能力が多様化し、複雑な挙動をするカードも増えました。インフレにより一度の盤面に絡んでくるカード枚数が増えたことも相まって、現代デュエマにおけるルール判断は非常に難解で、カジュアルプレイヤーにとって大きな障壁となっています。

いちプレイヤーとしてこの問題を解決するため、誰でも自然言語でカジュアルに問い合わせられるルール判定AIを開発しようと思い立ちました。

## 想定ユーザー層
### メインターゲット
ルールについての知識に乏しいカジュアルプレイヤー
### サブターゲット
その他ガチ勢（ガチ勢にとっても普通にデュエマのルールは難解）

### 補足事項
カジュアル層はあまりこのようなサービスにお金を払いたがらない上、そもそもデュエマはカジュアルプレイヤーの少ない煮詰まり切った環境なので、ビジネスとしては厳しい

## 想定ユースケース
### カジュアル勢
- 対戦時のジャッジとして当AIを用いる(一番素直な使い方だが、要求される精度は非常に高くなる)
### ガチ勢
- 意見が割れたときに当AIを用いてルールの根拠を検索し、相手に見せる
- デッキを構築するにあたり関連するルール判断を当AIを用いて確認する

## 設計方針
- コスト回収が難しいためなるべくコストの掛からない手段を用いる。LLMに関してもあまり高価なモデルは使えない。
- 速度にはあまりこだわらない。どの道LLMのレイテンシが支配的であるため。
- 完璧な精度は難しいが、せめて判断の参考になる情報は提示したい。公式ルールと公式Q&Aの引用を徹底。
- UIについては、競合の少ないプロダクトなので目を引く派手さはなくていいが、頻繁に触ってもらうことを想定したサービスなので手触りにはこだわりたい



## 動かし方

アプリは `web/` にあります。`web/.env.example` を `.env.local` にコピーし、`GEMINI_API_KEY` か `DEEPSEEK_API_KEY` を設定してから `npm run dev` で起動してください。

公式カードDBのミラーは、公式サイトのデータを再配布しないためリポジトリに含めていません。なくても動きます（カード名の候補表示が出ず、カード情報は公式サイトからその都度取得します）。手元で作る場合は `npm run mirror:cards` → `npm run build:cards` を実行してください。全件で数時間かかります。デモ環境は、手元で作ったミラーを同梱しています。
